# 作品简介

## 项目名称（约20字）

**基于多 Agent 的汽车销售自主成交智能助手**

---

## 作品简介（500 字以内）

传统汽车销售依赖人工经验：线索分散多渠道、画像靠个人判断、推荐报价试驾金融割裂、金牌经验难沉淀，导致线索流失率高、成交周期长。面向 4S 店与经销商，构建覆盖「线索—画像—成交—售后—沉淀」的多 Agent 自主销售闭环。

以 AgentTeams 为协同基点（8 Worker + TeamLeader，路由调度+上下文传递+协同执行+状态追踪），辅以 11 Skill 能力抽象、22 工具 MCP 等价契约、RAG 与 Agent 记忆、OTel GenAI 语义工具层可观测。区别于仅回答问题的客服，本方案能自主推进成交：低风险自动执行，高风险动作由百炼 LLM 自主推理 approve/reject/pending，决策与执行分离，审计 append-only 留痕。

已在真 AgentTeams v1.1.2 框架上一天跑通 3 场景全闭环（24 个 DAG 节点全绿，116 次工具调用 100% 成功，3 份闭环报告），每场景均触发 L2 风控审批、系统自主停止让利并转人工；运行中 4 类真实故障（mention 过滤丢弃、假派发、LLM 超时、空回合）全部代码级根治。另具备自检 56/56、评估 1.0、OTel 工具层可观测。Skill/Agent 身份/MCP 契约可复用，可迁移房产、保险、金融等场景。
