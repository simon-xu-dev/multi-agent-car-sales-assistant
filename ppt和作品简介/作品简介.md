# 作品简介

## 项目名称（约20字）

**基于多 Agent 的汽车销售自主成交智能助手**

---

## 作品简介（500 字以内）

汽车销售高度依赖人工经验：线索分散多渠道、画像靠个人判断、推荐报价试驾金融各自为政、金牌经验难沉淀，导致线索流失率高、成交周期长。面向 4S 店与经销商集团，构建「线索—画像—成交—售后—沉淀」多 Agent 自主销售闭环；问题在高客单价、长决策链销售中普遍存在，可迁移房产、保险、金融等行业。

核心思路：让 AI 像金牌销售一样自主推进成交，而非只做问答。以 AgentTeams 为基点，Manager→TeamLeader→Worker 分层编排 8 个职能 Agent；11 个 Skill 固化销售经验，MCP 契约连接 CRM/库存/金融，RAG 保障决策只依据可溯源证据。关键设计是决策与执行分离：低风险自动执行，高风险经 L2 审批门禁（LLM 三态审批），触底转人工，审计 append-only 留痕。

已在真 AgentTeams 框架上单日跑通 3 场景全闭环：24 个 DAG 节点全绿、116 次工具调用 100% 成功，每场景均触发 L2 风控且系统正确停止让利/转人工；运行中 4 类真实故障全部根治。Agent/Skill 清单与 MCP 契约随代码包开放、持续迭代。
