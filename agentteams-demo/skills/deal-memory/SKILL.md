# Deal Memory（成交记忆检索）

## Purpose

当任意 Agent 需要参考历史成交案例或客户历史记忆来支撑当前决策时使用。这是方案 RAG 体系中的「Agent 记忆存储」能力：时间窗口查询 + 语义检索统一入口。

## Inputs

- 检索查询（客户画像摘要 / 需求关键词 / 场景标签）。
- 客户 ID（用于记忆检索，如历史互动、历史成交）。

## 调用条件

- 触发：任意 Agent 需要历史成交案例或客户历史记忆支撑决策时（画像推断、策略参考、话术生成）。
- 不触发：事实数据（价格/库存/政策）以实时工具为准，不降级为记忆检索。

## 依赖工具 / 系统

- `mock_knowledge.search_case`（案例 RAG）、`mock_crm.get_customer_history`（Agent 记忆存储）。
- 向量检索 + 时间窗口查询（方案 RAG 能力 1「Agent 记忆存储」实现）。

## Procedure

1. 按客户 ID 检索客户历史记忆（购车记录、保养、续保、活动、历史会话）。
2. 按查询语义检索历史成交案例（相似画像、相似需求、成功路径）。
3. 按相关度返回 Top-N（默认 3 条），每条附来源引用。
4. 检索结果只作为决策参考，不替代事实数据（价格/库存/政策以实时工具为准）。

## Output Contract

```json
{
  "query": "二胎家庭六座 SUV 预算 25 万",
  "memory": [
    {"time": "2025-07-02", "event": "门店到访", "detail": "静态体验理想 L7 六座布局"}
  ],
  "similar_cases": [
    {"case_id": "CASE-...", "title": "2025-11 家庭 SUV 成交案例", "summary": "试驾前置 + 置换补贴测算", "similarity": "high"}
  ]
}
```

## Quality Gates

- 案例引用必须带 case_id 与来源，禁止模糊引用。
- 历史记忆仅用于增强判断，不得作为价格/库存等事实数据的来源。
- 检索为空时明确返回空结果，禁止编造相似案例。

## 失败处理

- 检索超时/失败：降级为无记忆参考，Agent 基于实时工具数据决策并标注"无案例参考"。
- 检索结果冲突：按相关度排序取 Top-N，标注冲突项供人工核对。

## 权限与安全

- L0 只读；客户记忆数据按最小化原则访问，检索日志留痕。
- 记忆存储属于 RAG「Agent 记忆存储」实现，满足赛题 RAG 能力 1。

## 复用价值

记忆 + 案例双通道检索可复用于客服知识库、理赔历史、金融客户画像等场景；是知识沉淀闭环的读取端，与 case-mining 成对设计。
