# Intent Scoring（意图识别与分级）

## Purpose

当画像完成后需要判断"这条线索值不值得投入、按什么节奏跟进"时使用。将购车信号翻译成分数与优先级，避免人工经验口径不一。

## Inputs

- 结构化画像。
- 会话文本中的购买信号。
- 意向分级 SOP。

## 调用条件

- 触发：画像构建完成需要确定跟进优先级时；客户产生新购买信号（主动询价/约试驾）需重新评分时。
- 不触发：仅资讯浏览类会话（自动低分，不推高成本策略）；信号不足以定级时输出低置信度。

## 依赖工具 / 系统

- `mock_crm.get_lead`（线索与当前状态）、`mock_knowledge.search_sop`（意向分级 SOP）。
- 信号字典（预算 +2 / 试驾 +2 / 价格异议 +1 / 时间约束 +2 / 资讯 -1）。

## Procedure

1. 提取信号并按权重打分：预算明确 +2；提到试驾/到店 +2；价格异议/比价 +1；时间约束 +2；仅资讯浏览 -1。
2. 映射购车阶段：认知（<30）、比较（30-60）、决策（60-80）、购买（>80）。
3. 输出跟进优先级 P0/P1/P2 与下一步动作。
4. 低意向线索标记 nurture 而非放弃，交由客户运营周期触达。

## Output Contract

```json
{
  "lead_id": "LEAD-2001",
  "intent_score": 78,
  "stage": "decision",
  "priority": "P1",
  "signals": [{"signal": "明确预算", "weight": 2}],
  "recommended_action": "24 小时内安排试驾 + 输出报价",
  "evidence_refs": ["session:phone@10:20"]
}
```

## Quality Gates

- 评分必须有信号清单支撑，禁止只输出总分。
- 单信号不得直接定级高意向。
- "未回复"不算负向信号。

## 失败处理

- 信号不足：输出低置信度分级并建议补充采集（如邀约到店）。
- 无法确定阶段：默认按 nurture 处理，不推送高成本策略。

## 权限与安全

- L0 只读；分级结果可写回 CRM 状态机（update_lead_stage），属于状态变更而非资金动作。

## 复用价值

信号字典机制可复用于房产、保险等高价值线索运营；分级结果直接驱动资源分配，是智能客服自主闭环方向二的关键 Skill。
