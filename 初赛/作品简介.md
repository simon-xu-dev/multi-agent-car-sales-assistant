# 作品简介

## 项目名称（约20字）

**基于多 Agent 的汽车销售自主成交智能助手**

---

## 作品简介（500 字以内）

传统汽车销售依赖人工经验：线索分散于官网、微信、电话、门店难以统一，画像靠个人判断，推荐、报价、试驾、金融流程割裂，金牌经验无法沉淀，导致线索流失率高、成交周期长。本方案面向 4S 店与经销商，构建覆盖「线索获取—需求分析—成交促进—售后运营—知识沉淀」的多 Agent 自主销售闭环。

技术路线以 AgentTeams 为协同基点，辅以 Skill 能力抽象、MCP 工具连接、RAG 知识增强与全链路可观测，并以 Nacos、Higress、PolarDB、RocketMQ 等推荐工具链承载治理。

区别于仅回答问题的传统智能客服，本方案能自主推进成交：低风险动作（报价、试驾）自动执行，高风险动作（超授权优惠、征信、订单）走人工审批与回滚审计，议价底线守护防止无限让利；成交案例自动沉淀为可复用 Skill，越用越强。

成果开放：11 个可复用 Skill、8 个 Agent 身份定义、MCP 集成契约均可独立复用与开源，可迁移至房产、保险、金融等高客单价销售场景。已交付可运行代码包，工具网关自检 36/36 通过，含审批、回滚、RAG、Trace 闭环证据。
